# 📚 Library Passport

A clean, simple web map for tracking every library you've visited within a library
system — like a passport you stamp as you go.

Pick your library system, see every branch on a map, and mark the ones you've been
to. Great for readers working their way through every branch in their county, city,
or state.

## Features

- **Pick your library system** — start typing to search a built-in list of US
  library systems, or enter your system manually if it's not listed.
- **Explore the map** — every branch shown as a pin. Click one for its address,
  hours, phone, and website.
- **Search** — quickly find a branch by name.
- **Mark visits** — flip the "Visited" toggle on each library and watch your
  completion stats climb.
- **See what's open now** — libraries closed at the current local time are greyed
  out, based on their posted opening hours.
- **Completion stats** — a progress bar showing how many branches you've visited.
- **Your progress stays with you** — everything is saved right in your browser, so
  your visited branches are still here when you come back. Nothing is uploaded, and
  no account is needed.

## Data & attribution

Library locations come from [OpenStreetMap](https://www.openstreetmap.org/), the
free, community-maintained map of the world. If a library is missing or a detail is
wrong, you can fix it directly on OpenStreetMap and it'll show up here.
