Deliver federal IMLS PLS data — phone, address, operator:wikidata, name — into JOSM as pre-filled suggestions you review before uploading.

JOSM-first workflow. Start JOSM, enable Remote Control (Preferences → Remote Control → “Enable remote control”), and keep it running. “Send” loads the existing library into a single named review layer with the fill-blank tags already applied — no per-tag prompts. Conflicts (where PLS differs from an existing tag) are shown for review only and never sent. Review every change before uploading. Missing branches? Those live on the Data QA page.

Overview

Suggestions are additive only — a tag is proposed only when the OSM element is missing it; existing values are never changed. Addresses are suggested only where the PLS geocode is precise, and the street/house-number split is conservative (ambiguous addresses are skipped). Website isn’t offered — PLS doesn’t collect it.
